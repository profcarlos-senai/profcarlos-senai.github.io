## Passo 4: Criando os Endpoints de Banana

Vamos organizar nosso código criando pacotes (packages) para cada tipo de classe. Primeiramente, crie o pacote `controle` dentro de `br.senai.meuprojeto`.

---

### Endpoint 1: Retornando a palavra "banana"

Vamos criar o primeiro endpoint que escuta requisições na URL `/banana`.

Explicação das anotações:

* `@RestController`: Informa ao Spring que esta classe é um controlador de rotas web e que os retornos dos métodos devem ser enviados diretamente no corpo da resposta HTTP (JSON ou Texto).
* `@GetMapping`: Mapeia requisições HTTP do tipo GET para o caminho especificado.

Crie o arquivo `BananaController.java` com o código abaixo:

```java
package br.senai.meuprojeto.controle;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

// @RestController: Marca a classe como um controlador REST
@RestController
public class BananaController {

    // @GetMapping: Define a rota de acesso via requisição HTTP GET
    @GetMapping("/banana")
    public String getBanana() {
        return "banana";
    }
}

```

> **Teste no Navegador:**
> Execute o projeto na classe `MeuprojetoApplication.java`. Abra o navegador e acesse:
> `http://localhost:8080/banana`
> **Resultado esperado:** A palavra `banana` exibida na tela.

---

### Endpoint 2: Multiplicando a banana por `n` vezes

Agora vamos evoluir o controlador adicionando um caminho dinâmico `/banana/{n}`, onde `{n}` é um parâmetro numérico passado pela URL.

Nova anotação:

* `@PathVariable`: Extrai variáveis informadas diretamente na URL e as vincula aos parâmetros do método Java.

Atualize o arquivo `BananaController.java` adicionando o novo método:

```java
package br.senai.meuprojeto.controle;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class BananaController {

    @GetMapping("/banana")
    public String getBanana() {
        return "banana";
    }

    // @PathVariable: Captura o valor informado em {n} na URL e passa para a variável 'n'
    @GetMapping("/banana/{n}")
    public String getBananaMultiplicada(@PathVariable int n) {
        return "banana ".repeat(Math.max(0, n)).trim();
    }
}

```

> **Teste no Navegador:**
> Acesse: `http://localhost:8080/banana/5`
> **Resultado esperado:** `banana banana banana banana banana`

---

### Endpoint 3: Retornando a imagem da banana

Agora vamos criar o endpoint `/banana/img` que redirecionará o usuário para a imagem de uma banana.

Nova anotação e classe:

* `RedirectView`: Classe do Spring Web usada para redirecionar a requisição HTTP para uma URL externa ou interna.

Adicione o método de imagem ao arquivo `BananaController.java`:

```java
package br.senai.meuprojeto.controle;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.servlet.view.RedirectView;

@RestController
public class BananaController {

    @GetMapping("/banana")
    public String getBanana() {
        return "banana";
    }

    @GetMapping("/banana/{n}")
    public String getBananaMultiplicada(@PathVariable int n) {
        return "banana ".repeat(Math.max(0, n)).trim();
    }

    // RedirectView: Redireciona a chamada HTTP para outro endereço web
    @GetMapping("/banana/img")
    public RedirectView getBananaImg() {
        String urlImagem = "https://upload.wikimedia.org/wikipedia/commons/thumb/a/af/Bananas_%28Alabama_Extension%29.jpg/1920px-Bananas_%28Alabama_Extension%29.jpg?_=20210330154646";
        return new RedirectView(urlImagem);
    }
}

```

> **Teste no Navegador:**
> Acesse: `http://localhost:8080/banana/img`
> **Resultado esperado:** O navegador será redirecionado para a foto das bananas na Wikipedia.

---

### Otimizando o Controller com `@RequestMapping`

Note que todos os métodos acima começam com a rota `/banana`. Podemos refatorar a classe definindo o caminho base usando a anotação `@RequestMapping` na classe, evitando repetição de código.

Nova anotação:

* `@RequestMapping`: Mapeia um prefixo de URL para todos os métodos de um determinado Controller.

Substitua todo o conteúdo de `BananaController.java` por esta versão otimizada:

```java
package br.senai.meuprojeto.controle;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.servlet.view.RedirectView;

@RestController
// @RequestMapping: Define o prefixo base '/banana' para todas as rotas desta classe
@RequestMapping("/banana")
public class BananaController {

    // Responde a: GET /banana
    @GetMapping
    public String getBanana() {
        return "banana";
    }

    // Responde a: GET /banana/{n}
    @GetMapping("/{n}")
    public String getBananaMultiplicada(@PathVariable int n) {
        return "banana ".repeat(Math.max(0, n)).trim();
    }

    // Responde a: GET /banana/img
    @GetMapping("/img")
    public RedirectView getBananaImg() {
        String urlImagem = "https://upload.wikimedia.org/wikipedia/commons/thumb/a/af/Bananas_%28Alabama_Extension%29.jpg/1920px-Bananas_%28Alabama_Extension%29.jpg?_=20210330154646";
        return new RedirectView(urlImagem);
    }
}

```

## Passo 5: Criando a Calculadora HTTP

Agora crie um novo Controller chamado `CalcController.java` dentro da pasta `controle`.

Nova anotação:

* `@RequestParam`: Captura parâmetros passados via Query String na URL (exemplo: `?n1=10&n2=5`).

Copie o código a seguir, que já implementa a operação de **soma**:

```java
package br.senai.meuprojeto.controle;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/calc")
public class CalcController {

    // @RequestParam: Extrai os query params (?n1=X&n2=Y) da URL
    @GetMapping("/somar")
    public String somar(@RequestParam double n1, @RequestParam double n2) {
        double resultado = n1 + n2;
        return "Resultado da Soma: " + resultado;
    }
}

```

> **Teste no Navegador:**
> Acesse: `http://localhost:8080/calc/somar?n1=10&n2=5`
> **Resultado esperado:** `Resultado da Soma: 15.0`

---

### ✏️ DESAFIO PARA OS ALUNOS:

Com base no método `somar`, crie sozinhos os outros três métodos dentro da classe `CalcController`:

1. `subtrair`: atenda no endpoint `/calc/subtrair?n1={n1}&n2={n2}`
2. `multiplicar`: atenda no endpoint `/calc/multiplicar?n1={n1}&n2={n2}`
3. `dividir`: atenda no endpoint `/calc/dividir?n1={n1}&n2={n2}` *(Trate a divisão por zero caso ache necessário!)*

## Passo 6: Retornando Objetos JSON com a Classe Pessoa

Em APIs REST modernas, é muito comum enviar e receber dados estruturados no formato JSON. O Spring Boot faz essa conversão de Objetos Java para JSON de forma totalmente automática!

### 1. Criando o Pacote Modelo e a Classe Pessoa

Crie o pacote `modelo` dentro de `br.senai.meuprojeto`. Sua árvore de pastas agora deve ser a seguinte:

```text
meuprojeto
└── src
    └── main
        └── java
            └── br
                └── senai
                    └── meuprojeto
                        ├── controle
                        │   ├── BananaController.java
                        │   └── CalcController.java
                        ├── modelo
                        │   └── Pessoa.java
                        └── MeuprojetoApplication.java

```

Dentro de `modelo`, crie o arquivo `Pessoa.java`:

```java
package br.senai.meuprojeto.modelo;

import java.math.BigDecimal;
import java.time.LocalDate;

public class Pessoa {

    private String nome;
    private String telefone;
    private int idade;
    private LocalDate dataContrato;
    private BigDecimal salario;

    // Construtor completo
    public Pessoa(String nome, String telefone, int idade, LocalDate dataContrato, BigDecimal salario) {
        this.nome = nome;
        this.telefone = telefone;
        this.idade = idade;
        this.dataContrato = dataContrato;
        this.salario = salario;
    }

    // Getters e Setters
    public String getNome() {
        return nome;
    }

    public void setNome(String nome) {
        this.nome = nome;
    }

    public String getTelefone() {
        return telefone;
    }

    public void setTelefone(String telefone) {
        this.telefone = telefone;
    }

    public int getIdade() {
        return idade;
    }

    public void setIdade(int idade) {
        this.idade = idade;
    }

    public LocalDate getDataContrato() {
        return dataContrato;
    }

    public void setDataContrato(LocalDate dataContrato) {
        this.dataContrato = dataContrato;
    }

    public BigDecimal getSalario() {
        return salario;
    }

    public void setSalario(BigDecimal salario) {
        this.salario = salario;
    }
}

```

---

### 2. Criando o PessoaController

Agora, crie o arquivo `PessoaController.java` dentro da pasta `controle`.

```java
package br.senai.meuprojeto.controle;

import br.senai.meuprojeto.modelo.Pessoa;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.math.BigDecimal;
import java.time.LocalDate;

@RestController
@RequestMapping("/pessoa")
public class PessoaController {

    @GetMapping
    public Pessoa getPessoa() {
        // Instancia um objeto Pessoa populado com dados fictícios
        return new Pessoa(
                "Carlos Eduardo",
                "(41) 99999-8888",
                28,
                LocalDate.of(2023, 3, 15),
                new BigDecimal("4500.50")
        );
    }
}

```

## Que tal salvar esse projeto no GitHub?

Agora que você concluiu o desenvolvimento e testou sua aplicação, é hora de salvar seu código na nuvem criando um repositório no **GitHub**.

### 1. Criando um Novo Repositório no GitHub

1. Acesse o site do [GitHub](https://github.com/) e faça login em sua conta.
2. Clique no botão **"+"** no canto superior direito e selecione **New repository** (ou clique no botão verde **New**).
3. No campo **Repository name**, digite o nome `spring-28-set` ou qualquer outro que você prefira
4. Mantenha o repositório como **Public** ou **Private** (conforme preferir).
5. **ATENÇÃO:** Deixe desmarcadas as opções de adicionar *README*, *.gitignore* ou *license*, pois já criamos a estrutura localmente e o repositório deve ser criado inteiramente **vazio**.
6. Clique em **Create repository**.

---

### 2. Associando o Repositório Remoto (Remote Origin)

Após criar o repositório, o GitHub exibirá a página do projeto com a URL do seu repositório (exemplo: `https://github.com/seu-usuario/spring-28-set.git`).

Abra o terminal integrado do seu IntelliJ IDEA e execute o comando abaixo para vincular seu repositório local ao repositório remoto no GitHub (substitua `seu-usuario` pelo seu nome de usuário do GitHub e `spring-28-set` pelo nome que você criou):

```bash
git remote add origin [https://github.com/seu-usuario/spring-28-set.git](https://github.com/seu-usuario/spring-28-set.git)
```

3. Garantindo o Commit Final

Para ter certeza de que todas as últimas alterações estão salvas antes do envio, execute:

```bash
git status
git add .
git commit -m "projeto spring boot concluido"
```

(Se o terminal informar que não há nada para commitar, significa que você já fez o commit de todas as alterações anteriormente. Pode prosseguir!)

4. Enviando o Código para o GitHub (Push)

Defina a branch principal como main (opcional, mas o github prefere esse nome) e envie o código para o repositório remoto executando os comandos:
Bash

git branch -M main
git push -u origin main

    📌 Verificação Final:

    Atualize a página do seu repositório no GitHub (https://github.com/seu-usuario/spring-28-set). Todo o código do projeto, histórico de commits e a estrutura das pastas agora estarão salvos na sua conta!
